# Codeparity color theme

A dark/light terminal + web theme for codeparity artifacts.
2 variants.
- **Dark** 
  accents are nudged slightly cooler/more saturated and a new "teal" brand
  accent is added (used for links/focus/cursor), then every text and
  accent token is re-verified for WCAG AA contrast.
- **Light** 
  is a custom-built companion (warm paper neutrals, not an
  inversion of dark) matched to the same hue identity per role, also
  WCAG AA–verified.

## Layout

- `src/palette.json` — single source of truth (generated by `src/gen_palette.py`)
- `src/gen_palette.py` — builds the palette, contrast-adjusting accents via HSL binary search
- `src/check_contrast.py` — WCAG AA report for every token (`python3 src/check_contrast.py`)
- `src/gen_terminal.py` — emits everything in `dist/terminal/` + the spec doc
- `src/gen_css.py` — emits `dist/web/codeparity.css`
- `dist/terminal/` — `codeparity-{dark,light}.alacritty.toml`, `.kitty.conf`, `.windows-terminal.json`
- `dist/web/codeparity.css` — CSS custom properties (`--cp-*`), auto dark/light via `prefers-color-scheme` + manual `data-theme` override
- `dist/spec/codeparity-ansi-spec.md` — format-agnostic ANSI 16 + extended token reference, for porting to any other tool

## Regenerating

```
cd src
python3 gen_palette.py      # rebuild src/palette.json
python3 check_contrast.py   # verify AA (exits 1 on any failure)
python3 gen_terminal.py     # rebuild dist/terminal/* + dist/spec/*
python3 gen_css.py          # rebuild dist/web/codeparity.css
```

Edit the seed colors or contrast targets in `gen_palette.py`, rerun the
pipeline above, and every output file regenerates from the same source.
